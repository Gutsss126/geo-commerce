将 WooCommerce 产品与客户订单同步到 GEO Commerce 管理后台。

== Installation ==
1. 上传 geo-commerce-connector 到 wp-content/plugins/
2. 在 WordPress 后台启用插件
3. 安装并启用 WooCommerce
4. 设置 → GEO Commerce：填写 GEO API 地址与 API 密钥

== 配置 ==
从 GEO Commerce 后台「WordPress」页面复制：
- API 地址（如 http://localhost:3000）
- 站点 API 密钥（X-GEO-API-Key）
