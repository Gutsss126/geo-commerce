# GEO Commerce 文档下载

本目录包含 Word 格式文档，可直接用 Microsoft Word / WPS 打开。

| 文件 | 说明 |
|------|------|
| GEO-Commerce-产品手册.docx | 产品功能、架构、API、模块说明 |
| GEO-Commerce-使用文档.docx | 安装、部署、WordPress 配置、GEO 优化实操 |

## 重新生成

修改 `docs/source/` 下 Markdown 后执行：

```bash
npm run docs:word
```

源文件：
- docs/source/产品手册.md
- docs/source/使用文档.md
