## 1. 环境准备与安装

### 1.1 系统要求

- Node.js 18+  
- npm 或 pnpm  
- WordPress 5.8+、PHP 7.4+（使用插件时）  
- WooCommerce（订单同步需要）  

### 1.2 获取代码

进入项目目录 geo-commerce。

### 1.3 安装依赖

```bash
npm install
```

### 1.4 配置环境变量

复制 .env.example 为 .env：

```env
DATABASE_URL="file:./prisma/dev.db"
NEXT_PUBLIC_APP_NAME="GEO Commerce"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

**生产环境**参考 .env.production.example：

```env
NEXT_PUBLIC_APP_URL="https://geo.fancrafti.com"
```

## 2. 首次启动

```bash
npx prisma db push      # 创建数据库表
npm run db:seed         # 演示数据（可选）
npm run db:seed:fancrafti   # 预置 fancrafti.com 站点（可选）
npm run dev             # 启动开发服务器
```

浏览器打开：http://localhost:3000

---

## 3. 添加站点（FanCrafti 示例）

### 3.1 手动添加

1. 左侧菜单 → **站点管理**  
2. 填写表单：

| 字段 | FanCrafti 示例 |
|------|----------------|
| 品牌名 | FanCrafti |
| 域名 | fancrafti.com（不含 https） |
| WordPress 地址 | https://fancrafti.com |
| 平台 | WordPress + WooCommerce |
| 语言 | en-US 或 zh-CN |
| 品牌语调 | 专业、创意手工材料、强调可验证规格 |

3. 点击 **创建站点并生成基线审计**  
4. 进入 **WordPress** 页，复制 **API 密钥**（geo_ 开头）

### 3.2 脚本预置

```bash
npm run db:seed:fancrafti
```

终端会输出站点 ID 与 API Key。

## 4. WordPress 插件配置

### 4.1 安装插件

1. 将 `wordpress/geo-commerce-connector` 文件夹上传到：  
   `wp-content/plugins/geo-commerce-connector/`  
2. WordPress 后台 → **插件** → 启用 **GEO Commerce Connector**  
3. 确认 **WooCommerce** 已安装并启用  

### 4.2 插件设置

路径：**设置 → GEO Commerce**

| 配置项 | 本地开发 | 生产（fancrafti.com） |
|--------|----------|------------------------|
| GEO API 地址 | http://localhost:3000 | https://geo.fancrafti.com |
| API 密钥 | 从后台复制 | 从后台复制 |
| 启用同步 | ✓ | ✓ |

**重要：** 线上 WordPress 无法访问 localhost，生产必须用 HTTPS 公网地址。

### 4.3 验证同步

1. 在 WooCommerce 编辑任意产品 → **更新**  
2. GEO 后台 → **产品 GEO** → 应出现该产品及 GEO 分  
3. 创建或更新一笔订单 → **订单管理** → 应出现 `WC-订单号`

## 5. 生产环境部署

### 5.1 架构

```
https://fancrafti.com          ← 你的店
        ↓
https://geo.fancrafti.com      ← GEO 后台（子域名或 Vercel）
```

### 5.2 方式 A：Vercel

1. 代码推 GitHub → Vercel Import  
2. 环境变量：DATABASE_URL（PostgreSQL）、NEXT_PUBLIC_APP_URL  
3. 将 prisma schema provider 改为 postgresql 后 db push  
4. 自定义域名 geo.fancrafti.com  

### 5.2 方式 B：同服务器 Nginx

- 反代 127.0.0.1:3000 → geo.fancrafti.com  
- Certbot 配置 SSL  
- pm2 或 systemd 保持 Node 进程运行  

详细步骤见：docs/fancrafti-production.md

### 5.3 生产启动

```bash
npm run build
npm run start
```

## 6. 后台各页面操作说明

### 6.1 总览（/）

查看站点数、产品数、订单数、平均 GEO 分；点击待优化 SKU 或最近订单进入详情。

### 6.2 站点管理（/sites）

- 添加新站、查看各站 GEO 分  
- **重新审计**：更新站点级 GEO 报告  

### 6.3 产品 GEO（/products）

- **录入产品**：选手动添加或依赖 WP 同步  
- 表格查看 SKU、品类、GEO 分  
- **重新审计**：保存后刷新分数  

### 6.4 订单管理（/orders）

- 筛选状态：待付款、已付款、处理中等  
- **新建订单**：填用户 ID、联系方式、地址、多行 SKU  
- 点击订单号 → 详情页可 **更新状态**  

### 6.5 审计报告（/audits）

- 查看历史站点/产品审计  
- 按 **修复建议** 逐条改 WooCommerce 内容  

### 6.6 GEO 工具箱（/tools）

**llms.txt：**

1. 选择站点 → 点击 **生成/更新**  
2. 复制预览内容  
3. 上传到 WordPress 根目录为 llms.txt  
4. 验证：https://fancrafti.com/llms.txt  

**产品描述增强：**

1. 找到低分产品 → **增强描述**  
2. 复制后台中更新后的描述到 WooCommerce 长描述  
3. 保存产品触发同步 → **重新审计**  

**FAQ 建议：**

- 复制 4 条 Q&A 到产品页 FAQ 区块或 Accordion 插件  

**JSON-LD Schema：**

- 复制预览 JSON，嵌入产品页（主题 footer 或 SEO 插件自定义 Schema）  
- 或通过 API 动态拉取  

### 6.7 AI 引用追踪（/citations）

1. 在 ChatGPT / Perplexity 搜索你的品类词  
2. 若出现 fancrafti.com 引用 → **记录引用**  
3. 填引擎、查询词、片段、URL  
4. 定期回顾，优化未被引用的 SKU  

### 6.8 WordPress 集成（/integrations/wordpress）

- 查看 API 端点、密钥  
- **重新生成密钥**（旧密钥立即失效，需同步改插件配置）

## 7. GEO 优化实操流程（推荐 3 周）

### 第 1 周：连接与基线

- [ ] 部署 GEO 后台到 HTTPS 公网  
- [ ] 安装并配置 WP 插件  
- [ ] 同步全部主要产品  
- [ ] 运行站点审计，填写品牌语调  

### 第 2 周：产品内容

- [ ] 在 **产品 GEO** 按分数从低到高排序  
- [ ] 对 GEO &lt; 60 的 SKU：增强描述 + FAQ + 补规格数字  
- [ ] 标题：品牌 + 品类 + 卖点，20–80 字符  
- [ ] 描述 300 字以上，含对比句  
- [ ] 每改一个产品 → WP 保存 → 后台重新审计  

### 第 3 周：站点级信号

- [ ] 部署 llms.txt 到 fancrafti.com 根目录  
- [ ] 主要产品页添加 JSON-LD Product Schema  
- [ ] Shipping / Returns / FAQ 政策页链接写入 llms.txt  
- [ ] 在 **AI 引用追踪** 记录首批测试结果  

### 持续维护

- 每周：检查待优化 SKU、新上架产品自动审计  
- 每月：总览平均 GEO 分、引用记录对比  
- 新订单/热卖款：优先优化对应 SKU

## 8. API 与 CLI 使用示例

### 8.1 产品审计（curl）

```bash
curl -X POST https://geo.fancrafti.com/api/audit/product \
  -H "Content-Type: application/json" \
  -d '{"title":"Craft Kit Pro","description":"Weight 500g, includes 12 colors","category":"Craft/Kit"}'
```

### 8.2 获取 llms.txt

```bash
curl https://geo.fancrafti.com/api/llms/fancrafti.com
```

### 8.3 产品 Schema

```bash
curl "https://geo.fancrafti.com/api/schema/product?domain=fancrafti.com&slug=your-product-slug"
```

### 8.4 CLI

```bash
npm run cli -- audit:product --title "Craft Kit" --desc "500g 12 colors"
npm run cli -- llms --name "FanCrafti" --domain fancrafti.com
```

## 9. 常见问题

**Q：插件同步无数据？**  
A：检查 API 地址是否为 HTTPS 公网、密钥是否正确、主机是否允许 wp_remote_post 出站、WooCommerce 是否启用。

**Q：GEO 分一直很低？**  
A：看 **审计报告** 具体未达标项；常见原因是描述太短、无 FAQ、无规格数字、无规范 URL。

**Q：订单用户 ID 显示 guest？**  
A：访客下单正常；登录用户显示 WooCommerce customer_id。

**Q：能否只用 WordPress 不用 WooCommerce？**  
A：产品可同步；订单同步需要 WooCommerce。

**Q：如何更换 API 密钥？**  
A：WordPress 集成页 → 重新生成密钥 → 同步更新插件配置。
