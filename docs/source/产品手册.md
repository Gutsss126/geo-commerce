# GEO Commerce 产品手册

**版本：** 0.1.0  
**适用对象：** 电商独立站运营者、WordPress/WooCommerce 店主、市场与 SEO/GEO 负责人  
**示例站点：** https://fancrafti.com/

---

## 1. 产品概述

### 1.1 什么是 GEO Commerce？

GEO Commerce 是一套面向**电商独立站**的 **GEO（Generative Engine Optimization，生成式引擎优化）** 平台，包含：

- **管理后台**：站点、产品、订单、审计报告、AI 引用追踪
- **GEO 优化工具**：llms.txt、JSON-LD Schema、FAQ 建议、描述增强
- **审计引擎**：站点级与产品级自动评分与修复建议
- **WordPress 插件**：WooCommerce 产品与订单自动同步
- **REST API / CLI**：供主题、插件、CI 流水线集成

### 1.2 GEO 与传统 SEO 的区别

| 维度 | 传统 SEO | GEO |
|------|----------|-----|
| 目标 | 搜索引擎排名 | AI 问答中的发现与正确引用 |
| 主要场景 | Google 搜索结果 | ChatGPT、Perplexity、Google AI Overview 等 |
| 内容要求 | 关键词、外链 | 可验证事实、FAQ、结构化数据、llms.txt |
| 成功指标 | 点击与排名 | AI 是否引用你的 URL 与产品事实 |

### 1.3 适用平台

- **主推：** WordPress + WooCommerce（内置插件同步）
- **支持标记：** Shopify、SHOPLINE、自研 Headless
- **部署：** 本地开发、VPS 子域名、Vercel + PostgreSQL

## 2. 功能模块

### 2.1 总览仪表盘（/）

- 接入站点数、产品条目数、订单数
- 平均 GEO 分、AI 引用记录数
- 待优化 SKU 列表（GEO 分 &lt; 60）
- 最近审计与最近订单摘要
- 快捷入口：站点、订单、工具箱、产品

### 2.2 站点管理（/sites）

- 添加/管理独立站（域名、平台、语言、品牌语调）
- WordPress 站点可填 WP 地址（如 https://fancrafti.com）
- 创建站点时自动生成 API 密钥与基线站点审计
- 支持重新运行站点 GEO 审计

### 2.3 产品 GEO（/products）

- 录入或同步 WooCommerce 产品
- 字段：标题、SKU、slug、品类、价格、URL、描述
- 自动 GEO 评分（0–100）与最后审计时间
- 支持手动重新审计

**产品审计检查项（7 项）：**

1. 标题可引用性（建议 20–80 字符）
2. 事实密度（规格、数字、材质等可验证信息）
3. 问答结构（FAQ）
4. 对比意图（vs、相比、适合什么人）
5. 规范 URL（canonical 产品链接）
6. 品类语义（清晰品类路径）
7. 内容深度（建议 300+ 字）

### 2.4 订单管理（/orders）

- 订单列表、状态筛选、统计成交额
- 订单字段：用户 ID、订单号、联系方式、收件地址、SKU 明细、金额、状态
- 手动新建订单（支持多 SKU 行）
- 订单详情与状态流转：待付款 → 已付款 → 处理中 → 已发货 → 已签收 / 已取消
- WooCommerce 同步订单号前缀：`WC-`

### 2.5 审计报告（/audits）

- 站点与产品历史审计记录
- 每项检查得分、状态（通过/警告/未达标）、修复建议
- 总体 GEO 分与摘要说明

### 2.6 GEO 工具箱（/tools）

| 工具 | 说明 |
|------|------|
| llms.txt 生成 | 声明 AI 爬虫可索引范围、联系信息、重点产品、政策页 |
| 产品描述增强 | 注入规格、场景、对比、售后等 GEO 友好结构 |
| FAQ 建议 | 每产品 4 条问答模板，可嵌入 WooCommerce |
| JSON-LD Schema | Product 结构化数据预览，供主题/SEO 插件使用 |

### 2.7 AI 引用追踪（/citations）

- 记录 ChatGPT、Perplexity、Google AI Overview、Claude、Copilot 等引擎的查询与引用片段
- 按引擎统计引用次数
- 用于验证 GEO 优化效果并迭代内容策略

### 2.8 WordPress 集成（/integrations/wordpress）

- 插件安装说明、API 端点、站点 API 密钥管理
- 支持重新生成密钥
- 生产环境部署提示（HTTPS 公网地址）

## 3. WordPress 插件

### 3.1 插件名称

GEO Commerce Connector

### 3.2 路径

wordpress/geo-commerce-connector → wp-content/plugins/geo-commerce-connector/

### 3.3 同步规则

| WooCommerce 事件 | GEO Commerce 行为 |
|------------------|-------------------|
| 保存/更新产品 | upsert 产品 + 自动 GEO 审计评分 |
| 新建/更新订单 | upsert 订单（用户 ID、SKU、数量、地址、电话、邮箱） |

### 3.4 鉴权

HTTP Header：`X-GEO-API-Key: <站点密钥>`

## 4. API 接口一览

### 4.1 GEO 审计

- POST /api/audit/product — 产品审计（无需入库）
- POST /api/audit/site — 站点审计

### 4.2 内容与 Schema

- GET /api/llms/[domain] — 获取 llms.txt 纯文本
- GET /api/schema/product?domain=&slug= — JSON-LD Product

### 4.3 订单

- GET /api/orders — 列表（siteId、userId、status 筛选）
- POST /api/orders — 创建订单
- GET/PATCH/DELETE /api/orders/[id] — 详情与状态

### 4.4 WordPress 集成

- POST /api/integrations/wordpress/products
- POST /api/integrations/wordpress/orders

## 5. CLI 命令

```bash
npm run cli -- audit:product --title "..." --desc "..."
npm run cli -- audit:site --name "FanCrafti" --domain fancrafti.com
npm run cli -- llms --name "FanCrafti" --domain fancrafti.com
npm run cli -- schema --title "..." --brand "FanCrafti" --price 99
npm run cli -- optimize:desc --title "..." --desc "..."
```

## 6. 技术架构

| 组件 | 技术 |
|------|------|
| 前端/后台 | Next.js 15、React 19、Tailwind CSS 4 |
| 数据库 | Prisma + SQLite（开发）/ PostgreSQL（生产推荐） |
| 校验 | Zod、TypeScript |
| 插件 | PHP 7.4+、WooCommerce |

### 6.1 数据模型

- Site：站点、平台、API 密钥、WordPress URL
- Product：产品、SKU、GEO 分、externalId
- Order / OrderItem：订单与行项目
- GeoAudit：审计报告 JSON
- Citation：AI 引用记录
- LlmsConfig：llms.txt 内容

## 7. 部署形态

### 7.1 本地开发

- npm install → prisma db push → npm run dev
- 默认 http://localhost:3000

### 7.2 生产（线上 WordPress 店）

- GEO 后台必须 **HTTPS 公网**（如 https://geo.fancrafti.com）
- WordPress 插件不可指向 localhost
- 环境变量 NEXT_PUBLIC_APP_URL 与访问域名一致

### 7.3 推荐架构（fancrafti.com）

```
https://fancrafti.com          ← WordPress + WooCommerce + 插件
        ↓ HTTPS POST
https://geo.fancrafti.com      ← GEO Commerce 管理后台
```

## 8. 评分标准说明

| GEO 分 | 等级 | 建议 |
|--------|------|------|
| 80–100 | 优秀 | 维持并追踪 AI 引用 |
| 60–79 | 良好 | 按审计建议逐项改进 |
| 0–59 | 待优化 | 优先处理 Top 销量 SKU |
